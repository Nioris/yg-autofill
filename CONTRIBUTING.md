# Вклад в проект

## Сообщения об ошибках

Перед созданием issue:

1. проверьте последнюю версию `yg-autofill.js`;
2. перезагрузите страницу и повторите запуск;
3. нажмите «Проверить поля страницы»;
4. сохраните встроенный лог;
5. подготовьте обезличенный JSON, который воспроизводит проблему.

В отчёте укажите браузер, URL-шаблон страницы, найденные/ненайденные поля и ожидаемый результат.

## Изменения кода

- Сохраняйте работу без сторонних зависимостей и сборки, если зависимость не даёт существенной пользы.
- Не добавляйте автоматическое нажатие «Сохранить» или «Отправить на модерацию» без отдельного обсуждения.
- Для категорий и тегов сохраняйте принцип точного совпадения.
- Любое автоматическое изменение текста должно отражаться в итоговом журнале.
- Новые селекторы добавляйте как дополнительные стратегии, не удаляя устойчивые резервные варианты без причины.

## Проверки

```bash
node --check yg-autofill.js
python tools/validate_json.py examples/*.json
```

После изменения DOM-логики проверьте минимум:

- один язык;
- несколько языков;
- отсутствующую языковую вкладку;
- текст длиннее лимита;
- отсутствующий тег;
- уже выбранную категорию;
- пустое необязательное поле;
- повторный запуск скрипта.
