# Журнал программы

YG Autofill пишет сообщения одновременно в два места:

1. встроенное окно журнала в панели;
2. Console браузера с префиксом `[YG]`.

## Уровни

| Уровень | Значение |
|---|---|
| `INFO` | этапы работы, выбранный язык, найденный элемент, текущая длина |
| `OK` | успешное заполнение или выбор |
| `WARN` | автоматическое обрезание, частичный итог, отсутствующее необязательное значение |
| `ERROR` | поле не найдено, значение сброшено, JSON повреждён, точный вариант тега отсутствует |
| `DEBUG` | технические детали, таблицы проверки, видимые варианты списка |

Счётчик рядом с кнопкой «Показать лог» — количество записей `WARN` и `ERROR`, а не количество уникальных неисправностей.

## Пример успешного обрезания

```text
[14:19:15.318] INFO  Описание игры: textarea#description568867[name="description"]; длина 1085/1000
[14:19:15.319] WARN  Описание игры: превышен лимит 1085/1000; обрезаю с конца на 85 символов, итоговая длина 1000
[14:19:15.512] OK    Описание игры: заполнено после обрезки 1085→1000
```

## Пример отсутствующего тега

```text
[14:19:19.073] INFO  Тег 10/12: выбираю «машины»
[14:19:22.884] ERROR Тег «машины»: точный вариант «машины» не найден в списке Яндекса
[14:19:23.530] ERROR Теги: выбрано 11/12; ошибки: машины
```

Остальные теги продолжают обрабатываться.

## Типы итогов

### `ИТОГ`

Все ожидаемые поля заполнены, ошибок и обрезаний нет.

### `ИТОГ С АВТООБРЕЗКОЙ`

Все ожидаемые поля заполнены, но один или несколько текстов были укорочены. Лог автоматически открывается и перечисляет каждое поле.

### `ИТОГ С ОШИБКАМИ`

Есть незаполненные поля, ошибки выбора или аварийная ошибка языка/дополнительного блока. Обрезания при этом показываются отдельным разделом.

## Сохранение журнала

- «Копировать» копирует весь текущий журнал.
- «Скачать» создаёт UTF-8 TXT-файл.
- «Очистить» удаляет записи и сбрасывает счётчик.

Имя скачанного файла содержит App ID и время:

```text
yg-autofill-568867-2026-08-19T14-19-23-728Z.log.txt
```

## Что прикладывать к отчёту об ошибке

1. Скачанный журнал с момента запуска скрипта.
2. Версию YG Autofill.
3. Версию браузера.
4. Снимок формы и панели.
5. Обезличенный JSON или хотя бы структуру проблемного поля.
6. Результат кнопки «Проверить поля страницы».

Не публикуйте секретные данные, токены, закрытые URL и сведения, не относящиеся к воспроизведению проблемы.
