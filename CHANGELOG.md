# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## 12.0 — 2026-08-19

- Добавлено автоматическое обрезание текстовых значений до фактического лимита поля.
- Добавлена итоговая сводка с исходной и итоговой длиной каждого обрезанного поля.
- Добавлен встроенный журнал с уровнями `INFO`, `OK`, `WARN`, `ERROR`, `DEBUG`.
- Добавлены копирование, скачивание и очистка журнала.
- Добавлены независимые флажки заполнения категорий, тегов и ключевых слов.
- Категории и теги выбираются только при точном совпадении с вариантом Яндекса.
- Добавлено заполнение короткого описания из `subtitle` или `short_description`.
- Добавлена проверка восьми полей текущей страницы.
- Расширен поиск элементов по App ID, селекторам и видимым подписям.
- Добавлена поддержка имён файлов с браузерным суффиксом `(1)` при отсутствии `lang`.
- Добавлена полная документация, JSON Schema и локальный валидатор примеров.
