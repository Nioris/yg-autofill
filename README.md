# YG Autofill

**Автозаполнение карточки игры в консоли Яндекс Игр из JSON**

Загружает локализации, заполняет текстовые поля, категории, теги и ключевые слова, учитывает лимиты и сохраняет подробный журнал выполнения.

> [!IMPORTANT]
> YG Autofill — независимый инструмент. Проект не является официальным продуктом Яндекса и не связан с Яндексом.

## Зачем это нужно

При публикации игры с несколькими локализациями одни и те же поля приходится заполнять вручную для каждого языка. YG Autofill переносит данные из подготовленных `store-listing-*.json` прямо в открытую форму черновика.

Скрипт работает локально в браузере. Он не нажимает «Сохранить» и не отправляет игру на модерацию — финальная проверка и сохранение остаются за пользователем.

## Важное правило: категории, теги и ключевые слова

> [!WARNING]
> Не придумывайте значения `category` и `tags` произвольно. Они должны соответствовать вариантам, которые реально доступны в выпадающих списках **Консоли Яндекс Игр**.

### Категории

- Категория выбирается из списка Яндекс Игр в Консоли.
- Можно выбрать **не более двух** категорий.
- В JSON рекомендуется копировать название категории **точно так, как оно отображается в Консоли**.
- YG Autofill выбирает только точное совпадение. Если такого варианта нет, программа не подставляет похожую категорию и записывает ошибку в лог.

Пример:

```json
"category": [
  "Казуальные",
  "Экономические"
]
```

### Теги

- Теги также выбираются из доступного списка Яндекс Игр в Консоли.
- Можно добавить **до 20 тегов**.
- В JSON нужно использовать реальные названия вариантов из списка Яндекса.
- YG Autofill не заменяет отсутствующий тег похожим значением.

Например, если в JSON указано:

```json
"tags": ["машины"]
```

а варианта `машины` нет в текущем списке Яндекса, тег будет пропущен и попадёт в итоговый отчёт как ошибка выбора.

### Ключевые слова

Ключевые слова устроены иначе: официальная документация Яндекс Игр **не задаёт для них предопределённого списка**.

Требования Яндекса:

- слова должны соответствовать тематике и содержанию игры;
- используются в нижнем регистре;
- разделяются запятыми;
- общий лимит поля — **100 символов**.

Пример:

```json
"keywords": [
  "кликер",
  "машины",
  "автозавод",
  "суперкар"
]
```

YG Autofill объединит массив в строку вида:

```text
кликер, машины, автозавод, суперкар
```

### Где смотреть актуальные правила

Официальная документация Яндекс Игр:

- [Заполнение черновика — категории, теги и ключевые слова](https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft)
- [Требования к игре](https://yandex.ru/dev/games/doc/ru/concepts/requirements)

Отдельной публичной страницы с полным статическим перечнем всех допустимых категорий и тегов в документации Яндекса на данный момент нет. **Актуальным источником списка является выпадающий список непосредственно в Консоли Яндекс Игр.** Он может изменяться, поэтому YG Autofill намеренно не хранит собственный жёстко заданный справочник категорий и тегов.

## Возможности

- загрузка одного или нескольких языковых JSON-файлов;
- автоматическое добавление и переключение языковых вкладок;
- заполнение названия, SEO-описания, полного и короткого описания, инструкции «Как играть»;
- опциональное заполнение категорий, тегов и ключевых слов;
- автоматическое обрезание текста до фактического лимита поля;
- итоговый отчёт: что заполнено, что обрезано и где произошли ошибки;
- выбор категорий и тегов только по точному совпадению;
- проверка доступности полей страницы до запуска;
- встроенный лог с уровнями `INFO`, `OK`, `WARN`, `ERROR`, `DEBUG`;
- копирование и сохранение журнала в TXT;
- резервный поиск элементов по App ID, `id`, `name`, `aria-label`, селекторам и видимым подписям.

## Быстрый старт

1. Откройте страницу черновика игры в Консоли Яндекс Игр.
2. Откройте DevTools → **Console**.
3. Откройте [`yg-autofill.js`](yg-autofill.js), скопируйте файл целиком и вставьте его в консоль.
4. Нажмите **«Загрузить store-listing-*.json»**.
5. Выберите один или несколько JSON-файлов.
6. При необходимости включите **Категории**, **Теги** и **Ключевые слова**.
7. Нажмите **«Проверить поля страницы»**.
8. Нажмите **«Заполнить все языки»**.
9. Проверьте итоговый лог и саму форму.
10. Сохраните изменения вручную в интерфейсе Яндекс Игр.

Подробная инструкция: [`docs/USAGE.md`](docs/USAGE.md).

## Что заполняется

| Ключ JSON | Поле в Консоли | Тип | Ограничение / источник |
|---|---|---|---|
| `title` | Название игры | строка | до 50 символов |
| `seo_description` | Описание для SEO | строка | до 160 символов |
| `about` | Об игре / Описание игры | строка | до 1000 символов |
| `subtitle` | Короткое описание | строка | до 70 символов; также `short_description` |
| `how_to_play` | Как играть | строка | до 1000 символов |
| `category` | Категории | строка / массив | только варианты из списка Консоли; не более 2 |
| `tags` | Теги | строка / массив | только варианты из списка Консоли; до 20 |
| `keywords` | Ключевые слова | строка / массив | свободные тематические слова; нижний регистр; до 100 символов |

Сначала YG Autofill пытается определить реальный лимит непосредственно из формы Яндекс Игр. Значения выше используются как резервные.

## Формат JSON

Рекомендуемое имя файла:

```text
store-listing-ru.json
store-listing-en.json
store-listing-de.json
```

Минимальный вариант:

```json
{
  "lang": "ru",
  "title": "Название игры",
  "subtitle": "Короткое описание игры",
  "seo_description": "Описание для поисковых систем.",
  "about": "Полное описание игры.",
  "how_to_play": "Объяснение управления и правил."
}
```

Полный вариант:

```json
{
  "lang": "ru",
  "title": "Название игры",
  "subtitle": "Короткое описание",
  "category": [
    "Казуальные",
    "Экономические"
  ],
  "tags": [
    "тапалки",
    "с прокачкой"
  ],
  "keywords": [
    "кликер",
    "машины",
    "завод"
  ],
  "seo_description": "Описание для поисковых систем.",
  "about": "Полное описание игры.",
  "how_to_play": "Правила и управление."
}
```

Полный пример: [`examples/store-listing-ru.json`](examples/store-listing-ru.json).

Чистый шаблон: [`examples/store-listing-template.json`](examples/store-listing-template.json).

JSON Schema: [`schema/store-listing.schema.json`](schema/store-listing.schema.json).

Подробное описание формата: [`docs/JSON_FORMAT.md`](docs/JSON_FORMAT.md).

## Языки

Код языка берётся прежде всего из поля `lang` внутри JSON. Если его нет, скрипт пытается определить язык по имени файла.

Поддерживаются:

`ru` · `en` · `es` · `pt` · `tr` · `de` · `fr` · `it` · `ja` · `ko` · `zh` · `ar` · `hi` · `id`

Если один язык загружен несколько раз, используются данные последнего загруженного файла.

Категории, теги и ключевые слова являются общими полями карточки. Для них используется русский JSON (`lang: "ru"`), а если русского файла нет — первый загруженный JSON.

## Автообрезка и лимиты

Если текст длиннее разрешённого, YG Autofill:

1. определяет допустимый максимум;
2. срезает лишние символы с конца;
3. заполняет поле допустимым значением;
4. проверяет, что интерфейс принял изменение;
5. добавляет запись в итоговый отчёт.

Пример:

```text
ОБРЕЗАНО ПРИ ЗАПОЛНЕНИИ:
— Русский → Описание игры: 1085→1000
  срезано 85 символов
```

Обрезание выполняется технически, а не по смысловой границе предложения. После заполнения рекомендуется вручную проверить конец обрезанного текста.

## Журнал программы

Лог доступен прямо в панели YG Autofill и одновременно дублируется в Console с префиксом `[YG]`.

| Уровень | Значение |
|---|---|
| `INFO` | обычный ход выполнения |
| `OK` | операция выполнена успешно |
| `WARN` | есть важное замечание |
| `ERROR` | поле или операция не выполнены |
| `DEBUG` | техническая диагностическая информация |

Журнал можно показать/скрыть, скопировать, очистить и скачать как `.txt`.

Подробнее: [`docs/LOGGING.md`](docs/LOGGING.md).

## Проверка JSON

```bash
python tools/validate_json.py examples/store-listing-ru.json
```

Для нескольких файлов:

```bash
python tools/validate_json.py store-listing-*.json
```

Превышение текстового лимита считается предупреждением, потому что YG Autofill умеет автоматически обрезать значение при заполнении.

## Если что-то не работает

1. Нажмите **«Проверить поля страницы»**.
2. Повторите заполнение.
3. Откройте **«Показать лог»**.
4. Сохраните или скопируйте журнал.

Типовые проблемы: [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md).

## Безопасность

Код, вставленный в DevTools Console, выполняется с правами открытой страницы. Перед запуском проверяйте источник файла и изменения в коде.

YG Autofill не содержит собственных сетевых запросов для передачи данных проекта наружу. JSON читается локально в браузере, после чего скрипт взаимодействует с уже открытой страницей Консоли Яндекс Игр.

Подробнее: [`SECURITY.md`](SECURITY.md).
