# YG Autofill

YG Autofill — локальный JavaScript-помощник для заполнения карточки игры в консоли Яндекс Игр из одного или нескольких JSON-файлов. Скрипт добавляет панель поверх страницы, переключает языковые вкладки, заполняет текстовые поля, при необходимости выбирает категории и теги, ведёт подробный журнал и формирует итоговый отчёт.

Проект не является официальным продуктом Яндекса и не связан с Яндексом.

## Возможности

- Загрузка сразу нескольких языковых JSON-файлов.
- Автоматическое добавление и переключение языковых вкладок.
- Заполнение названия, SEO-описания, описания игры, короткого описания и инструкции «Как играть».
- Необязательное заполнение категорий, тегов и ключевых слов отдельными флажками.
- Автоматическое обрезание слишком длинных текстов до фактического лимита поля.
- Итоговая сводка с перечнем всех обрезанных полей и ошибок.
- Выбор категорий и тегов только при точном совпадении с вариантом Яндекса.
- Проверка полей текущей страницы до запуска.
- Встроенный журнал с уровнями `INFO`, `OK`, `WARN`, `ERROR`, `DEBUG`, копированием и сохранением в TXT.
- Поиск полей по нескольким признакам: App ID, `id`, `name`, селекторам и видимым подписям.

Скрипт не нажимает «Сохранить» и не отправляет игру на модерацию. После заполнения данные необходимо проверить и сохранить вручную.

## Быстрый запуск

1. Откройте страницу черновика игры в консоли Яндекс Игр.
2. Откройте инструменты разработчика браузера и вкладку Console.
3. Скопируйте целиком файл [`yg-autofill.js`](yg-autofill.js), вставьте его в консоль и нажмите Enter.
4. В появившейся панели нажмите «Загрузить store-listing-*.json» и выберите один или несколько JSON-файлов.
5. Отметьте дополнительные поля: категории, теги и/или ключевые слова.
6. Нажмите «Проверить поля страницы» и убедитесь, что нужные элементы найдены.
7. Нажмите «Заполнить все языки».
8. Просмотрите итог и журнал, затем вручную проверьте форму и нажмите «Сохранить».

Подробная инструкция: [`docs/USAGE.md`](docs/USAGE.md).

## Что заполняется

| Ключ JSON | Поле в консоли | Тип данных | Ориентировочный лимит | Поведение |
|---|---|---:|---:|---|
| `title` | Название игры | строка | 50 | Перезаписывается; лишнее обрезается с конца |
| `seo_description` | Описание для SEO | строка | 160 | Перезаписывается; лишнее обрезается с конца |
| `about` | Об игре / Описание игры | строка | 1000 | Перезаписывается; лишнее обрезается с конца |
| `subtitle` | Короткое описание | строка | 70 | Перезаписывается; поддерживается также `short_description` |
| `how_to_play` | Как играть | строка | 1000 | Перезаписывается; лишнее обрезается с конца |
| `category` | Категории | массив строк или строка | список Яндекса | Добавляются только точные совпадения; поддерживается также `categories` |
| `tags` | Теги | массив строк или строка | список Яндекса | Добавляются только точные совпадения |
| `keywords` | Ключевые слова | массив строк или строка | 100 | Массив объединяется через запятую и пробел; лишнее обрезается |

Сначала скрипт пытается определить реальный лимит из HTML-поля или счётчика Яндекса. Числа в таблице используются как резервные значения. Обрезание выполняется с конца без добавления многоточия. Каждое изменение фиксируется в итоговом логе.

## Минимальный JSON

```json
{
  "lang": "ru",
  "title": "Название игры",
  "subtitle": "Короткое описание игры",
  "seo_description": "Описание для поисковых систем.",
  "about": "Полное описание игры.",
  "how_to_play": "Объяснение управления и правил."
}
```

Полный пример с категориями, тегами и ключевыми словами находится в [`examples/store-listing-ru.json`](examples/store-listing-ru.json). Формальная схема находится в [`schema/store-listing.schema.json`](schema/store-listing.schema.json).

Полное описание формата: [`docs/JSON_FORMAT.md`](docs/JSON_FORMAT.md).

## Имена файлов и языки

Рекомендуемый шаблон имени: `store-listing-<код>.json`, например `store-listing-ru.json` или `store-listing-en.json`.

Главным источником кода языка является поле `lang` внутри JSON. Если его нет, скрипт пытается извлечь код из имени `store-listing-ru.json` или браузерной копии вида `store-listing-ru (1).json`. Если один язык загружен несколько раз, используются данные последнего файла.

Поддерживаемые коды: `ru`, `en`, `es`, `pt`, `tr`, `de`, `fr`, `it`, `ja`, `ko`, `zh`, `ar`, `hi`, `id`.

Категории, теги и ключевые слова являются общими полями карточки и заполняются один раз. Источником служит русский JSON (`lang: "ru"`), а при его отсутствии — первый загруженный файл.

## Как работает заполнение

1. Скрипт определяет App ID из URL, если он присутствует.
2. JSON читается локально в браузере; файл никуда отдельно не отправляется скриптом.
3. Для каждого языка скрипт добавляет отсутствующую вкладку и переключается на неё.
4. Текстовое поле ищется по старому ID с App ID, затем по `name`, `aria-label`, `data-testid`, CSS-селекторам и видимой подписи.
5. Перед записью определяется лимит. Слишком длинное значение обрезается и заносится в отчёт.
6. Значение устанавливается через нативный setter поля и события `input`/`change`, чтобы интерфейс на React принял изменение.
7. Категории и теги вводятся по одному; выбирается только точный видимый вариант Яндекса.
8. После завершения выводится итог: количество заполненных полей, ошибки и перечень обрезаний.

Техническое описание: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Важные особенности

- Пустые локализованные текстовые значения пропускаются и не стирают поле.
- Категории и теги, уже выбранные в форме, не удаляются. Скрипт только добавляет отсутствующие значения из JSON.
- Если точного тега или категории в списке Яндекса нет, похожий вариант не выбирается автоматически.
- Изменения интерфейса Яндекс Игр могут потребовать обновления селекторов.
- Скрипт рассчитан прежде всего на Chrome/Chromium и запуск из DevTools Console.

## Проверка JSON из командной строки

В репозитории есть небольшой валидатор без внешних зависимостей:

```bash
python tools/validate_json.py examples/store-listing-ru.json
python tools/validate_json.py store-listing-*.json
```

Структурные ошибки дают ненулевой код завершения. Превышение лимита считается предупреждением, потому что YG Autofill умеет автоматически обрезать значение при заполнении.

## Журнал и диагностика

Кнопка «Показать лог» открывает журнал внутри панели. Его можно скопировать или сохранить как TXT. Сообщения дублируются в консоль браузера с префиксом `[YG]`.

Описание уровней и итогов: [`docs/LOGGING.md`](docs/LOGGING.md). Типовые проблемы: [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md).

## Безопасность

Код, вставленный в DevTools, выполняется с правами открытой страницы. Перед запуском проверяйте, что файл получен из доверенной версии репозитория и не содержит посторонних изменений. YG Autofill не содержит собственных сетевых запросов, но взаимодействует с уже открытой страницей консоли Яндекс Игр.

Подробнее: [`SECURITY.md`](SECURITY.md).
