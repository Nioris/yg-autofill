# Использование YG Autofill

## 1. Подготовьте JSON

Создайте один файл на каждый язык. Рекомендуемая схема имени:

```text
store-listing-ru.json
store-listing-en.json
store-listing-es.json
```

Внутри каждого файла укажите `lang` и локализованные текстовые поля. Категории, теги и ключевые слова достаточно хранить в русском файле, потому что они заполняются один раз для всей карточки.

Перед запуском можно проверить файлы:

```bash
python tools/validate_json.py store-listing-*.json
```

## 2. Откройте правильную страницу

Перейдите в консоль Яндекс Игр и откройте черновик нужного приложения. Скрипт предназначен для страницы, на которой видны поля названия, описаний, категорий, тегов и ключевых слов.

Если вкладка с данными приложения ещё не открыта, откройте её вручную до запуска.

## 3. Запустите скрипт

1. Откройте DevTools: обычно F12 или сочетание Ctrl+Shift+I.
2. Перейдите на вкладку Console.
3. Откройте файл `yg-autofill.js` из репозитория.
4. Скопируйте весь код, включая начало и конец.
5. Вставьте его в Console и нажмите Enter.

В правом верхнем углу страницы появится панель `YG Autofill v12.0`.

Повторный запуск новой копии скрипта удаляет предыдущую панель и создаёт свежую.

## 4. Загрузите файлы

Нажмите «Загрузить store-listing-*.json» и выберите один или несколько файлов.

После чтения файла панель показывает языковые кнопки, а журнал содержит:

- имя файла;
- определённый код языка;
- количество найденных текстовых полей;
- длину каждого значения;
- предупреждения о будущих обрезаниях;
- количество категорий и тегов.

Если один язык загружен несколько раз, последний файл заменяет предыдущий.

## 5. Выберите дополнительные поля

Флажки по умолчанию выключены:

- «Категории»;
- «Теги»;
- «Ключевые слова».

Категории и теги зависят от вариантов, которые Яндекс показывает в выпадающем списке. Скрипт не выбирает похожее значение и не угадывает замену. Это снижает риск незаметно поставить неправильный тег.

Ключевые слова заполняются как обычный текст. Если JSON содержит массив, он преобразуется в строку через запятую и пробел.

## 6. Проверьте поля страницы

Нажмите «Проверить поля страницы».

Проверяются восемь логических полей:

1. Название игры.
2. Описание для SEO.
3. Описание игры.
4. Короткое описание.
5. Как играть.
6. Ключевые слова.
7. Категории.
8. Теги.

Результат выводится в панель и через `console.table`. Если поле не найдено, откройте лог и сохраните его для диагностики.

Кнопка проверяет все поля независимо от выбранных флажков. Поэтому отсутствие категории или тегов будет видно даже тогда, когда их заполнение выключено.

## 7. Заполните все языки

Нажмите «Заполнить все языки».

Для каждого языка скрипт:

1. проверяет наличие языковой вкладки;
2. при необходимости открывает список и добавляет язык;
3. переключается на вкладку;
4. ожидает появления полей;
5. определяет лимиты;
6. обрезает слишком длинные значения;
7. записывает текст и проверяет, что интерфейс его не сбросил.

После локализованных полей один раз обрабатываются отмеченные категории, теги и ключевые слова.

Во время работы не переключайте вкладки страницы и не нажимайте элементы формы вручную: это может закрыть выпадающий список или изменить активный язык.

## 8. Прочитайте итог

Возможны три основных результата.

### Чистый итог

```text
ИТОГ: заполнено 8/8; ошибок нет; обрезаний нет
```

### Успех с обрезанием

```text
ИТОГ С АВТООБРЕЗКОЙ:
Заполнено 8/8.
Ошибок: 0.
Обрезано полей: 1.
ОБРЕЗАНО ПРИ ЗАПОЛНЕНИИ:
— Русский → Описание игры: 1085→1000 (срезано 85 символов)
```

### Частичный результат

```text
ИТОГ С ОШИБКАМИ:
Заполнено 7/8.
Ошибок: 1.
Обрезано полей: 1.
ОШИБКИ:
— Дополнительные поля: заполнено 2/3; ошибки выбора: Теги: машины
```

Число «Ошибок» в итоговой шапке означает количество проблемных групп: конкретный язык или блок дополнительных полей. Внутри журнала может быть несколько отдельных сообщений `ERROR`.

## 9. Проверьте и сохраните вручную

После завершения:

1. проверьте конец каждого обрезанного текста;
2. просмотрите выбранные категории и теги;
3. убедитесь, что активные языковые вкладки заполнены корректно;
4. нажмите «Сохранить» вручную;
5. только после проверки отправляйте карточку на модерацию.

YG Autofill намеренно не нажимает кнопки сохранения и модерации.

## Ручное заполнение одного языка

После загрузки файлов в панели появляются кнопки `RU`, `EN` и другие. Нажатие такой кнопки заполняет только локализованные текстовые поля выбранного языка. Дополнительные категории, теги и ключевые слова при этом не обрабатываются.

## Работа с логом

- «Показать лог» — открыть журнал.
- «Копировать» — поместить весь журнал в буфер обмена.
- «Скачать» — сохранить файл вида `yg-autofill-568867-<дата>.log.txt`.
- «Очистить» — удалить текущие записи и начать новый журнал.

При обращении с ошибкой прикладывайте сохранённый лог, версию браузера, URL-шаблон страницы без чувствительных параметров и обезличенный пример JSON.
