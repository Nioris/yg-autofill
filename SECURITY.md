# Security

## Модель выполнения

YG Autofill вставляется в DevTools Console и выполняется в контексте открытой страницы консоли Яндекс Игр. Такой код получает доступ к DOM страницы и может изменять форму от имени текущего пользователя.

Запускайте только проверенную копию из доверенного коммита или релиза. Не вставляйте в Console неизвестные модификации, сокращённые ссылки и команды, смысл которых не понятен.

## Сетевое поведение

Текущая версия YG Autofill не создаёт собственных `fetch`/XHR-запросов и не отправляет выбранные JSON-файлы на сторонние серверы. Файлы читаются локально средствами браузера. Сама страница Яндекс Игр и установленные расширения браузера могут выполнять собственные сетевые запросы независимо от скрипта.

## Сохранение данных

Скрипт изменяет видимые поля формы, но не нажимает «Сохранить» и не отправляет приложение на модерацию. Пользователь должен проверить результат и сохранить его вручную.

## Сообщение об уязвимости

Не публикуйте рабочие токены, cookie, приватные URL, персональные данные и другие секреты в публичном issue. Для первичного отчёта используйте обезличенное описание, версию скрипта и минимальный воспроизводимый пример.
